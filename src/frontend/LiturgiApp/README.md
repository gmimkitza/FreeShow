# LiturgiApp Module - FreeShow

Modul ini adalah ekstensi khusus untuk FreeShow yang menyediakan dukungan penuh untuk tata ibadah liturgi, dialog responsif, template khusus gereja, serta fitur tipografi lanjutan.

## Struktur Modul:
* **`templates.ts`**: Definisi kategori template dan template bawaan LiturgiApp (seperti *Dialog Liturgi*).
* Komponen penggaris visual terkait terletak di `src/frontend/components/edit/editbox/Ruler.svelte`.
